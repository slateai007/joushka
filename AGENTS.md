# Repository Workflow Rules

- Always submit repository changes through a pull request. Do not make changes directly on `main`.
- Every pull request must be opened in **Ready for review** state, never as a draft.
- Pull request titles must use exactly one of these formats:
  - `[Rachit]feat/<short-description>`
  - `[Rachit]fix/<short-description>`
  - `[Rachit]update/<short-description>`
- Choose `feat`, `fix`, or `update` according to the nature of the change, and use a concise kebab-case description.
